# My Hobbies Webpage

## Description
This project is a static webpage about my hobbies, it provides information about what i like to do in my free time.

## Features
- A homepage introducing my hobbies.
- Information about my favourite activities.
- A simple and user-friendly layout.

## Technologies Used
- HTML
- Bootstrap

## Installation
1. Download or clone this repository.
2. Open the `index.html` file in a web browser.
